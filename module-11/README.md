# Module 11 — Defence and certification

- `score.js` + `scores.example.json` — jury arithmetic for the 100-point system (seven dimensions;
  six scored for the team, individual defence scored per person). The completion rule in it is
  a **proposal until the Ministry approves it**.
  ```bash
  node score.js scores.example.json
  ```
- `pick-block.js` — the random-block practice from Module 10, run inside your Git repository:
  `node pick-block.js "<your name>"`.
- `check-drills.sh` and `drills.md` — the three live-change drills, with the look/check commands.

Config and example files hold synthetic names and scores only.
