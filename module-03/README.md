# Module 3 — Accessible pages

`site/` holds `index.html`, `form.html` and `style.css`.

Open `site/index.html` in a browser (double-click it). Both pages load `style.css`.
Check by keyboard only: Tab moves through every control in a sensible order and the focus
outline is always visible.

Not tested here: NVDA or another screen reader. The lab asks you to do that check yourself.
